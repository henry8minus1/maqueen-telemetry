# Changelog

## 1.0.0

- MakeCode extension with start/stop, status, supplied distance and opt-in Maqueen sensor polling.
- MicroPython module with V2 background scheduler and manual polling fallback.
- Shared receiver for official MakeCode sendString envelopes and compact Python frames.
- Four-robot graphical dashboard with actual LED pixels, raw sensor details and expected-lesson check.
- Downloadable single-file Python and MakeCode starters; classroom distribution guide.
- No robot movement, display writes, board resets or button-event consumption in telemetry libraries.
